# FlashNote 页面表面配色收敛设计

## 目标

修复 macOS 工作台中页面灰底、纯白卡片和侧边栏之间对比过强的问题。保留 FlashNote 的蓝色主操作识别，同时让内容区域呈现更安静、连续的层级。

## 视觉方案

采用“暖灰画布 + 柔白表面 + 克制边界”的单一浅色体系：

- 页面画布使用极浅暖灰，避免系统默认灰与纯白产生突兀跳变。
- 侧边栏使用比画布略亮的同色系表面，而不是独立的冷灰色块。
- 卡片使用接近画布的柔白表面，配合细边框和极弱阴影表达层级；不再依赖纯白大块与明显投影。
- 输入框、次级容器使用同一套浅层表面色，避免组件各自使用不同系统背景色。
- 品牌蓝仅用于选中导航、主要按钮、可操作图标和波形重点。
- 成功绿仅用于连接、完成等真实状态的标签；不改变页面主体配色。

## 实现边界

配色集中在 `DesignSystem/AppTheme.swift` 和通用 `Card` 组件中定义。各功能页面继续引用语义化令牌，不直接散布新的固定色值。

本次不更改信息结构、字体、间距、录音与设备交互逻辑，也不引入新的深色模式策略。

## 验收标准

1. 工作台、文件、录音笔、设置与详情页在浅色模式下使用一致的页面画布与卡片层级。
2. 侧栏和主内容区不再出现明显冷灰／纯白断层。
3. 已选导航与“开始录音”仍保持清晰的品牌蓝识别。
4. 状态绿不用于普通容器背景。
5. macOS 与 iOS 都能构建成功，macOS 发布包内包含这次变更。
