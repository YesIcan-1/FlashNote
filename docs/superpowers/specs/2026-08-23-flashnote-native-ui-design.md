# FlashNote 原生产品界面设计

**日期：** 2026-08-23  
**状态：** 用户已确认，进入实现

## 目标

将已确认的 FlashNote 产品原型 1:1 落地为 macOS / iOS 原生 SwiftUI 界面。该界面以「正在处理的录音」为中心，而不是以设备调试功能为中心；保留原 App 的功能范围，但不沿用原 App 的大块宫格布局。

## 视觉语言

- 采用低饱和蓝紫强调色、暖白内容面和柔和层次，夜间模式使用同一语义色板反转，不通过硬编码白色修补。
- 正文优先使用系统字体；时间、时长、文件大小采用等宽数字，保证扫读稳定。
- 卡片圆角、细描边和极浅阴影用于分组，不堆叠重阴影。
- 图标只承担辅助辨识，操作按钮始终带文字或明确可访问标签。

## 导航与页面

### 1. 工作台

- 顶部显示当天日期、问候、应用级搜索/快捷录音入口，以及已连接设备状态胶囊。
- 首卡是「继续处理」：展示最近一条录音的音频波形、时长、处理状态和主操作；无录音时显示明确的新建/导入入口。
- AI 摘要条仅展示真实已生成的纪要摘要；没有数据时说明如何生成，不展示模板内容。
- 最近录音为可点击行，统一进入录音详情页。

### 2. 录音详情

- 顶部显示标题、来源、日期、时长、状态和播放控制。
- 宽窗口左右并列：主列为全文转写，侧列为 AI 纪要；窄窗口按同一顺序堆叠。
- 录音、转写、纪要均来自同一稳定录音 ID。详情页提供重新转写、重新生成纪要和删除；没有音频或服务未配置时给出可操作说明。

### 3. 文件

- 顶部是搜索和「本地文件 / 设备文件」分段切换。
- 本地文件显示真实的录音标题、扩展名、大小、时长、处理状态和操作菜单，可进入详情或删除。
- 设备文件只有在用户主动选中时才启动设备会话；显示设备状态、刷新、真实电量/文件数量、文件下载进度和下载转写入口。
- 从设备下载完成后应在本地文件出现，并能进入同一个详情页。

### 4. 录音笔

- 页面独占设备会话，显示连接状态、电量、固件、录音状态和可用容量。
- 录音控制、实时会话、实时全文和设备文件分区呈现；不向其它页面常驻暴露录音笔面板。
- 录音状态按 QS668 协议准确映射：1=录制中、2=未录制、3=已暂停。
- 「高级」区域容纳设备巡检和调试指令，常用路径只保留连接、录音、暂停/保存、实时推流、刷新与下载。

### 5. 设置

- 分组展示外观、常用行为、转写、AI 纪要、上传服务和已记住设备。
- 外观支持跟随系统/浅色/深色，不要求本机密码。
- Qwen3-ASR、SenseVoiceSmall 后备、DeepSeek 和上传服务各有独立配置入口；模型读取与选择只保留一个来源，避免重复字段。
- API 密钥不在普通页面显示或记录日志。

## 交互原则

- 蓝牙仅在「录音笔」或用户主动切换到「设备文件」时触发；启动 App、进入工作台、打开本地文件均不请求蓝牙。
- 每个不可逆删除操作均二次确认，并说明删除的是本地副本还是设备源文件。
- 下载、转写、AI 纪要必须反映真实进度/错误，不使用成功模板或伪进度。
- 一小时级录音的下载、上传和转写都应具备恢复或明确失败边界；即时 UI 先显示已完成数据，不阻塞浏览其它录音。

## 验收

- 工作台最近内容和文件列表中的本地条目均可进入对应详情。
- 切换导航后已连接设备的电量、文件与状态仍然正确显示。
- 主题切换覆盖工作台、详情、文件、设备和设置，文字/背景对比合格。
- 设备文件和本地文件命名、`.wav` 扩展名及自适应大小一致；下载后可在本地文件与详情中找到。
- 所有已实现服务调用只处理真实音频/全文，未配置或失败时清晰说明下一步。
